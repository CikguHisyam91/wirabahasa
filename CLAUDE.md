# Arahan untuk Claude

- Pengguna ialah guru tanpa latar belakang pengekodan. Jawab dalam Bahasa Melayu.
- **Semua teks, item dan elemen dalam game mesti dalam Bahasa Melayu** (nama senjata, kuasa khas, HUD, butang, mesej).
- Selepas setiap perubahan: commit, push, **buat Pull Request ke `main` dan terus merge sendiri** (pengguna telah memberi kebenaran). Kemudian beritahu pengguna tunggu 1–2 minit dan tekan Ctrl + Shift + R.
